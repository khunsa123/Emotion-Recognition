# 🎭 Emotion Recognition

## 📌 Repository Overview

This repository is a growing collection of **emotion recognition research projects** spanning multiple modalities — speech, EEG, and physiological signals. Each project applies deep learning and signal processing techniques to classify human emotional states from different types of data.

> Projects are organised into individual folders, each with its own dedicated `README.md`, source code, and dataset references.

---

## 🎯 Research Goals

- Classify human emotional states from speech, EEG, and multimodal biosignals
- Evaluate and compare deep learning approaches across different emotion datasets and modalities
- Build toward a unified, multimodal emotion recognition framework
- Develop reproducible, publication-quality pipelines for affective computing research

## 🧠 Research Domains

- 🎙️ **Speech Emotion Recognition** — Deep learning on multi-corpus audio datasets
- 🧠 **EEG-based Affective Computing** — Emotion classification from neural signals
- 🔗 **Multimodal Emotion Analysis** — Fusing speech, EEG, and physiological signals
- 🤖 **Emotion-Aware AI** — Real-time classification for human–computer interaction
